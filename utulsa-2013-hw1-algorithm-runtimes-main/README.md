## Creating and analyzing algorithmic runtimes

We have seen examples of many of the algorithmic runtimes in class, 

Ultimately, we are concerned about how these algorithms perform as their input size approaches infinity; however, we would also like to see how these algorithms behave with increasingly larger input sizes.  

For each of the following algorithmic runtime classes:
- constant
- logarithmic
- linear
- quadratic
- cubic
- exponential
- factorial

Do the following:
1) Create a function that accepts a variable input size that implements an algorithm that represents the runtime class using the input.
2) Run the function with an increasing number of input sizes, recording the time taken for each input size. 
3) Generate enough data points to generate a chart that shows a trend (at least 10) #Matplotlib?
4) Plot the results. 

Given the difference in run time for each of the algorithms, they will not fit on the same graph.
